# AnuragPatil-cloud.github.io

Personal portfolio website of **Anurag Patil** — DevOps Engineer | Multi-Cloud Infrastructure, CI/CD Automation & SRE.

DevOps Engineer with 3+ years of experience in CI/CD, Terraform, and Kubernetes, mainly on AWS with hands-on work on Azure and GCP. Cut deployment failures from 18% to under 6%, reduced infrastructure setup time from 3 days to under 8 hours, and lowered incident detection time by 60% across 15+ production microservices.

Built with plain HTML, CSS, and JavaScript in a single file. No frameworks and no build step; the animation libraries load from CDNs.

## 🚀 Deployment

This site is hosted via **GitHub Pages**.

To deploy your own copy:
1. Fork this repository
2. Go to `Settings` → `Pages`
3. Set source to `main` branch / `root`
4. Your site will be live at `https://<your-username>.github.io`
